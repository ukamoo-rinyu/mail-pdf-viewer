# Feature Specification: ブラウザ版に合わせた画面・表示設定・リンク操作

**Created**: 2026-09-27

**Status**: Implemented

**Input**: 本家 mail-pdf-viewer のブラウザ版（MailPDFViewer.html）に合わせたデスクトップ版の画面刷新・表示設定・リンク操作を、kojiPDFviewer の既存機能（しおり一覧への切り替え、階層対象のメール一覧、階層数の増減、ページ番号入力、`file:` リンク、`.msg`/`.eml` 添付の照合、アイコン）を保ったまま取り込む。重なる機能は kojiPDFviewer の方式を優先する。

## User Scenarios & Testing

### User Story 1 - ブラウザ版と同じ画面で読む (P1)

利用者はブラウザ版と同じ配色・配置の画面でメール束PDFと一般資料PDFを読む。

**Acceptance Scenarios**:

1. 上部のツールバーはなく、最上部にタブ、一覧の上に検索欄・「しおり一覧へ」/「メール一覧へ」・「⚙ 表示設定」、一覧の下に件数と「一覧を隠す」がある。
2. PDF表示の上部中央に前後ページ、ページ番号入力（Ctrl+G）、表示の切り替え（幅に合わせる／ページ全体）、全画面ボタンがある。
3. メール一覧はカード表示で、選択中のカードは左端に青い線が付き、添付ファイルを全件表示する。
4. 各タブの ☆/★ でお気に入りを登録・解除できる。再インデックスと最近使ったPDFはタブの右クリックメニューから使える。
5. 全画面表示ではタブとステータスバーを隠し、PDF表示の上のバーは残す。終了するとウインドウの大きさと一覧の表示状態を全画面前に戻す。

### User Story 2 - 一覧の表示を変える (P1)

利用者は「⚙ 表示設定」で一覧の見え方を変え、次回起動時も同じ設定で使う。

**Acceptance Scenarios**:

1. メール一覧: 表示形式（カード／1行リスト）、並び順6種、件名でまとめる、文字サイズ、行の間隔、表示する項目、本文プレビューの行数、日時の表示形式を変えられる。
2. しおり一覧: 並び順（PDFの順番／名前順）、文字サイズ、行の間隔、長い名前の折り返し、ページ番号の表示を変えられる。
3. 並び順を変えても、選択中のメールまたはしおりとPDFの表示ページは変わらない。
4. 設定は開いているすべての同種タブに反映され、「初期設定に戻す」で既定値に戻る。

### User Story 3 - 本文中のリンクを開く (P2)

利用者は、PDFに埋め込まれたリンクに加え、本文に文字で書かれているだけのURL・メールアドレスもクリックで開く。

**Acceptance Scenarios**:

1. リンクにマウスを乗せると指カーソルになり、リンクを強調してリンク先をツールチップとステータスバーに表示する。
2. 埋め込みリンクは従来どおり開く（Web、`mailto:`、`file:`、PDF内のページ）。
3. 本文中の `http(s)://`・`www.` で始まる文字列とメールアドレスは、既定のブラウザ・メールアプリで開く。

### User Story 4 - 表示が変わっても同じページを見る (P2)

利用者が表示の切り替え、ウインドウの大きさの変更、一覧の表示/非表示、全画面の切り替え、メール一覧⇔しおり一覧の切り替えを行っても、見ていたページのまま読み続けられる。

## Edge Cases

- しおりと対応付けられない添付は従来どおり赤く表示し、押しても移動しない（kojiPDFviewer の方式を維持）。1行リストでは添付数を「移動できる数/全体」で赤く示す。
- 検索中はしおりの階層操作を無効にする（従来どおり）。
- ツールバーがないため、ツールバーの右クリックで表示を消して戻せなくなる状態は起きない（別ウインドウのツールバーでも右クリックメニューを出さない）。
- 開始画面の項目が画面に入り切らない場合はスクロールする。

## Requirements

- **FR-001**: kojiPDFviewer の既存機能と既存テストを維持する。
- **FR-002**: 一覧の表示設定を `QSettings("ukawa", "kojiPDFviewer")` の `mailView/` と `bookmarkView/` に保存する。
- **FR-003**: 「開いたときに展開する階層」の設定は設けず、しおりの階層は既存の「全展開 ＋ 数字 − 全折り」で操作する。
- **FR-004**: `MainWindow.page_control` と `MainWindow.search_box` は現在のタブのページ番号欄・検索欄を返す。
- **FR-005**: PDF、索引DB、既読状態、最近使ったPDF、お気に入りの形式は変えない。

## Success Criteria

- `python -m unittest discover -s tests -v` の既存11件が成功する。
- 実際のメール束PDFとしおり付きPDFで、表示設定の切り替え、リンクのクリック、全画面、メール一覧⇔しおり一覧の切り替え後も表示ページが保たれることを確認する。

## Assumptions

- 見た目の基準は本家のブラウザ版 MailPDFViewer.html（ライトテーマ）とする。
- Qt の描画スタイルは Fusion を使い、Windows のダークモードに関係なく明るい配色にする。
